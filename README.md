# 🌍 LifeBao

**LifeBao — Parler pour tous**

LifeBao est une plateforme sociale moderne conçue pour permettre aux utilisateurs de communiquer, partager du contenu, développer leur réseau et participer à une communauté numérique dynamique.

## ✨ Aperçu

LifeBao combine les fonctionnalités essentielles d'un réseau social moderne :

- 👤 Création de profils utilisateurs
- 🔐 Authentification sécurisée
- 📝 Publication de contenu
- 💬 Messagerie
- 🔔 Notifications
- 🔍 Recherche intégrée
